Think CSS is just for styling? Think again.

In this eye-opening talk, we explore how pure CSS features—like attribute selectors, font loading, and animations—can be leveraged to track user behavior, detect installed extensions, and extract sensitive data without executing a single line of JavaScript.

Learn about these security and privacy vectors and how to defend against them.
