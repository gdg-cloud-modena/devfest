With Generative UI, applications no longer display pre-designed screens: they generate components and layouts in real time based on context and user requests.

In this introductory talk, we'll explore what Gen UI is and how to transform LLM outputs into real, interactive UI components beyond plain text.

We will provide an overview of the main strategies: from custom solutions to Gen UI frameworks for React and Angular, all the way to MCP Apps and MCP UI—the emerging standard for creating widgets compatible with clients like ChatGPT, Claude Desktop, and VS Code.
