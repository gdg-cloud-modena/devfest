Con la Generative UI le applicazioni non mostrano più schermate progettate a priori: generano componenti e layout in tempo reale, in base al contesto e alle richieste di chi le sta usando.

In questo talk introduttivo vedremo cos'è la Gen UI e come trasformare l'output di un LLM in componenti veri e interattivi, andando oltre il semplice testo.

Faremo poi una panoramica delle principali strategie: dalle soluzioni custom ai framework Gen UI per React e Angular, fino a MCP Apps e MCP UI, il recente standard per creare widget compatibili con client come ChatGPT, Claude Desktop e VS Code.
