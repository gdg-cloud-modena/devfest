Validating a Jira ticket on a real Android device takes thirty minutes on a good day but can be days of hands-on testing when every edge case matters. What if the agent could do it for you? 

In this session, we'll explore two brand-new tools that make agent-driven Android QA real today: Trailblaze, Block's open-source AI automation framework, and Google's Android CLI v1.0, stable since I/O 2026. We'll see how to chain them with any LLM agent to read a Jira ticket and drive a real device end-to-end like handling Chrome Custom Tabs, app permissions or icon-only buttons along the way.

Can it cover everything? Can it really retire manual QA? Let's plug in a Pixel and see how far we get 🤖
