For years, the browser was a safe but isolated playground. If you wanted to communicate with a Bluetooth device, modify local files, or access a serial port, native development was the only route. That is no longer the case. Welcome to Project Fugu: the cross-company initiative created to close, once and for all, the capability gap between the Web and Native applications.

Together, we will explore some of the most powerful (and honestly, most fascinating) APIs that finally allow the Web to "talk" to hardware, manage local files, and integrate with the operating system just like a native app. Whether you build professional tools or are simply curious about the future of the Web, come see how the browser sandbox has transformed into a launchpad for the next generation of software.
